## 实施路线图

> 定位：组织级 Agent 数据基础设施（数据网关）。首个落地场景：陆向谦实验室（教育：会议 / 订单 / 用户数据）。
> 本文档融合项目书中"里程碑与计划 / 交付物 / 迭代策略"的内容，与 [三年技术与 AI 演进路线图](./evolution.md) 配合阅读。

---

## 一、总体迭代策略

- **路线**：核心数据源接入 → 商业结算与组织隔离 → 多协议接口与终端 → 外部 Agent 代办预处理 → 平台化与自研 AI 服务
- **节奏**：以双周为周期持续对齐三端代码（API / CLI / Admin）；已实现能力即刻文档化，规划中能力保持客观标注
- **优化**：以真实业务场景为驱动，打通“会议协作 ↔ 商业交易 ↔ 数字资产”闭环

## 二、阶段规划与实际达成度

### 阶段一：数据汇聚与业务闭环（已达成 ✅）
1. **基础设施与组织隔离**
   - nove-api（NestJS + Prisma 7 + PostgreSQL + Redis）骨架上线 ✅
   - 组织级多租户所有权隔离（`organizationId` 全链路穿透）✅
   - 人机统一认证、JWT 批量吊销与安全审计中心 ✅
   - 用户实名证件（Identity Document）加密管理与审核 ✅
2. **多源数据接入与集成中枢**
   - 会议数据接入：腾讯会议（`tmeet`）、飞书（`lark`）Webhook + API 同步 ✅
   - 企业微信（`wecom`）组织通讯录与用户同步 ✅
   - 商业与结算：Stripe 国际化支付/退款同步、微信小店订单/售后 ✅
   - 云盘存储（`drive`）：文件资产中心、目录归类、项目封面与商品媒体绑定 ✅
   - 中心化集成管理（`integrations`）与连通性自动自测服务（`TesterService`）✅
3. **商业激励与财务冲销引擎**
   - 订单权益周期计算、主动冻结与手工调整 ✅
   - 自动化月度与模块摊销分润核算 ✅
   - Cron 驱动全局退款冲销追回引擎（Refund Clawback Engine）✅
   - 组织成员月度工资条自动化生成 ✅

### 阶段二：多端开放与工具链演进（当前阶段 🟡）
1. **多协议对外接口**
   - RESTful API（Swagger/OpenAPI，全域 `@Auth()` 与领域异常）✅
   - GraphQL API（Apollo 生产模式）✅
   - MCP Server（SSE / Streamable HTTP 协议，首批 7 个基础工具）🟡
   - Agent Skill 包（`nove-skills` 会议技能参考）🟡
2. **多端应用生态**
   - **nove-admin**：人类管理工作台，完整落地 16 大业务、资产、分润与治理视图 ✅
   - **nove-cli**：命令行运维工具升级至 v1.3.0，覆盖 8 大模块，支持浏览器 OAuth 授权登录 ✅
3. **AI 智能加工（轻量可用，重型代办）**
   - 轻量 AI：会议纪要结构化转写、发言人总结、周期追踪报告已跑通 ✅
   - 重量 AI（过渡期）：借力 OpenClaw / Hermes 等外部 Agent 软件代办大批量关联与分析任务 🟡
   - 向量检索与语义层：pgvector 接入与混合检索 ⏳（规划中）

### 阶段三：平台化与自研 AI 服务（远期演进 ⏳）

## 三、当前交付物现状清单

### 1. 核心产品交付
- **nove-admin（人类管理中枢）**：覆盖 16 大模块（仪表盘、组织成员、本地/平台用户与实名证件、商业订单/退款/产品/渠道、分润看板与规则/工资条、项目管理、云盘存储中心、会议与紧凑转写、任务中心、追踪报告、集成管理与自测、安全设置）。
- **nove-cli（命令行工具链）**：v1.3.0 稳定版，覆盖 `auth`（浏览器 OAuth 交互登录）、`meeting`、`minute`（结构化转写与发言人观点提取）、`project`、`product`、`order`、`user`（含批量导入）、`tracking-report`。
- **开放接口**：RESTful API、GraphQL、MCP Server（7 大工具）、Agent Skill。

### 2. 技术与架构交付
- **后端主服务 nove-api**：NestJS + TypeScript，升级至 **Prisma 7** 驱动适配器，44 个模块化子模型架构，全量数据严格按 `organizationId` 逻辑隔离。
- **异步与调度中枢**：BullMQ 任务队列（状态流转与失败重试）+ 定时 Cron 调度引擎（自动冲销退款、定期数据对账）。
- **连接器中枢**：集中化 `configs` 模块，内置各大生态连通性自测器（`TesterService`）。

### 3. 安全与合规交付
- **人机统一权限模型**：RBAC 权限点映射 + AI OAuth Scope 白名单约束。
- **凭据与会话治理**：用户级/组织级批量失效 JWT 令牌；用户实名证件加密存管。
- **全链路溯源**：TraceId 穿透、Webhook 原始报文与验签记录可追溯可回放。
