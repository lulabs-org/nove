# 人机统一权限体系

> 权限是 nove 数据基础设施的核心支柱：**人类用户与 AI / Agent 均为独立访问主体**，全系统实现**组织所有权隔离（Organization Scoping）**与**细粒度权限管控**，AI 只能在被授权范围内访问数据，且每次访问全量可审计。

## 一、双主体模型

nove 将访问主体划分为两类，统一纳入权限管理：

| 主体 | 接入方式 | 授权模型 | 典型行为 |
|---|---|---|---|
| **人类用户** | nove-admin（Web 工作台） | 组织成员身份 + RBAC（角色 → 权限点） | 查看数据、管理数据源与集成、配置权限规则、审计 |
| **AI / Agent** | API / MCP / Skill / CLI（独立身份） | API Key（`sk_` 前缀）/ OAuth Scope 白名单 | 读取授权范围数据、执行数据提取与分析任务 |

> 原则：**AI 绝不复用人类账号**。每个 Agent 拥有独立身份凭据与独立授权，权限变更与凭证吊销互不影响。

## 二、组织级多租户隔离（Organization Scoping）

nove 采用严格的**组织所有权数据隔离模型**，确保各企业/组织间的数据边界坚固可靠：

### 2.1 组织上下文强注入
- **请求上下文透传**：每次 API 请求通过 `@Auth()` 装饰器自动提取当前操作者的组织上下文（`organizationId`）；
- **数据层强制约束**：会议（Meeting）、纪要（Minute）、项目（Project）、商业订单（Order）、集成服务配置（ServiceConfig）等核心实体均强绑定 `organizationId`，查询与写入操作默认隔离。

### 2.2 组织成员安全防护
- **超级管理员保护机制**：系统内置对组织超级管理员的防误删与防降权守卫，杜绝管理权锁死风险；
- **角色依赖绑定校验**：在移除组织成员或解绑角色前，前置校验依赖关系与业务归属，防止产生悬空引用。

## 三、权限模型

### 3.1 RBAC（基于角色的访问控制）
- **角色与权限点（Permission Codes）**：细粒度权限点覆盖菜单访问、按钮动作与 API 操作；
- **前端守卫与后端守卫对齐**：前端通过 `PermissionGuard` 与 `Perm` 组件控制界面显隐；后端通过 `PermissionGuard` 拦截越权调用。

### 3.2 ABAC（属性基础访问控制）
针对具体资源动态施加条件限制：
- 只能查看本部门或本分配范围的业务数据；
- 商业分润记录与工资条仅对本人或具备财务审计权限者开放。

### 3.3 AI Scope 白名单约束
AI / Agent 的每次访问受细粒度 Scope 严格约束：
- **数据源与模块范围**：如 `meeting:read`、`project:read`、`order:manage`、`product:read`；
- **操作受限**：默认只读权限，写操作需显式声明并申请对应 Scope；
- **CLI OAuth 授权**：nove-cli 登录支持请求指定的 Scope 范围，避免赋予过多越权能力。

## 四、身份认证与会话生命周期治理

### 4.1 认证方式
- **人类认证**：OAuth 2.0 授权码模式、JWT（短期令牌与滑动刷新）；
- **AI 凭据认证**：长期 API Key（固定 `sk_` 前缀，强制校验 User-Agent 头并绑定所属组织与 Scope）；
- **终端客户端**：nove-cli 支持浏览器一键跳转 OAuth 授权，自动完成本地凭据安全落盘。

### 4.2 会话安全与 JWT 批量吊销
- **用户级批量失效**：支持在安全设置中心一键批量吊销指定用户或本账号的所有已发 JWT 令牌，杜绝凭证泄露后的滞留风险；
- **安全审计中心**：记录敏感操作（密码变更、令牌失效、权限变更），提供用户安全审计日志。

### 4.3 实名证件合规体系（Identity Documents）
- **加密存储与审核流**：支持用户身份证、护照等实名凭据的上传、加密存管与管理员审核；
- **敏感信息隔离**：实名证件数据脱敏存储，仅对合规审核员开放密文解密查看，严控外泄渠道。

## 五、全链路审计与溯源

- **全要素审计日志**：记录谁（主体类型与 ID）、何时、自何处（IP/User-Agent）、访问了何种数据、执行了何种动作；
- **TraceId 全链路穿透**：请求经网关、nove-api、异步队列直至 AI 计算服务，全局透传唯一 TraceId；
- **Webhook 回放与排错**：第三方回调事件（腾讯会议、飞书、Stripe、微信小店）全量留存原始报文与验签记录，支持随时重放排错；
- **API Key 用量统计**：实时统计各 Agent API Key 的调用频次、成功率与数据消费量。

## 六、数据脱敏

- **自动识别脱敏**：手机号、身份证号、银行卡号等 PII 敏感信息在输出至非特权主体或常规 Agent 时默认模糊化；
- **多层级脱敏策略**：按组织角色、AI Scope 与 API 场景动态执行脱敏规则；
- **密钥集中托管**：脱敏与加密密钥由 Secret Manager / 环境变量安全隔离。
