# 陆向谦实验室（LuLabs）

> nove 的**首个落地合作方 / 客户**（教育场景，v1 样板）。本页为合作方简介与 nove 落地场景；合作方内部教学资料（PBL、试错教育、多师制、课程体系等）见合作方飞书知识库。

## 合作方简介

- **中文名称**：陆向谦实验室
- **英文名称**：LuLabs（硅谷 Lulab）
- **性质**：非盈利教育机构
- **定位**：直击全球创新前沿，培养未来创世领袖及其核心团队成员

陆向谦实验室源自清华大学，注册于美国硅谷，是一个开放式的在线精英教育实验室。实验室以培养具有全球视野、创新精神和多学科综合能力的青少年人才为使命，助力新一代在创新时代中脱颖而出。

传统课堂的影响范围有限，特别是在资源分布不均的情况下，许多偏远地区或非名校的学生难以接触到优质教育资源。通过将课程转到线上，可以突破地域限制，让更多学生有机会学习。

### 使命 / 愿景 / 价值观

- **使命**：通过项目式学习和创新教育，培养具备全球视野、创新精神与实践能力的复合型人才，帮助年轻学子实现非常规的自我实现
- **愿景**：打造一个有情怀的"网上斯坦福大学"，推动教育变革，构建学生为中心、面向未来的教育体系
- **价值观**：实战优先（学理论不如学案例，学案例不如做案例，做案例不如玩案例）、协作共赢、终身学习、非常规成长
- **目标**：培养具有专业能力与创新思维的综合型人才，适应未来社会需求
- **模式**：沉浸式学习与项目驱动（PBL），培养问题解决、团队协作和领导能力

## 发展历程

| 时间 | 事件 |
| --- | --- |
| 1994 | 陆向谦教授预见互联网将颠覆世界，开始关注创新教育模式 |
| 2007 | 在清华大学经济管理学院开设创新创业课程 |
| 2014.04 | 课程从清华课堂延伸到线上，开启互联网教育探索 |
| 2020 秋 | 与复旦大学联合授课，推动创新创业教育跨校协作 |
| 至今 | 形成系统化项目式学习模式，与国内外顶尖创业者和企业家合作，培养大批复合型人才 |

## 创始人简介

**陆向谦教授** —— 实验室创始人；清华经管学院创新创业课程教授；教育部全国高教教师网络培训中心创新/创业特聘教授；美国加州伯克利大学 Hass 商学院博士；美国西北大学 Kellogg 商学院工商管理硕士；清华大学工学硕士。曾策划摩托罗拉进入中国战略、任教于香港科技大学管理学院、投资基金负责人、创业家。

2007 年，他将斯坦福大学的创业教育课程理念引入中国，成为清华大学课堂的一部分，被誉为"国内创新创业教育第一人"。

## nove × 陆向谦实验室

作为 nove 的首个落地场景（v1 样板），双方围绕教育场景开展合作，验证"组织级 Agent 数据基础设施"在真实组织中的落地能力：

- **数据形态**：会议数据（课程/例会转写、摘要、行动项）、订单数据（课程报名/订单）、用户数据（学员/家长/导师）
- **落地价值**：把实验室散落在会议、订单、学员系统中的数据汇聚为统一数据资产，经 AI 预处理后供内部 Agent 与 nove-admin 使用
- **验证目标**：完成实验室级验证后，横向复制至其他教育机构、高校、企业培训与泛知识服务型组织
