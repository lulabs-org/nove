# 需求与范围

> 本文档承接 [项目概述](./overview.md)，阐述 nove 数据基础设施的核心用户、典型场景与 v1.0 范围边界。

## 核心用户

- **AI / Agent**：通过 API / MCP / Skill / CLI 读取授权范围数据、执行业务分析与操作任务（主要消费者）。
- **外部数据提供方**：会议协同、企业微信、Stripe、微信小店等外部生态，通过 Webhook 或开放 API 与 nove 互联。
- **人类用户（管理员 / 业务人员 / 财务人员）**：通过 nove-admin 查看业务全景、管理项目与云盘资产、配置权限、管理集成与自测、核对分润与退款冲销、审计 AI 访问。
- **开发者 / 运维方**：使用 nove-cli 执行日常数据管理与运维操作，或接入新数据源构建基于 nove 的 Agent 应用。

## 典型场景

- **多源数据汇聚**：会议记录（腾讯会议 / 飞书）、企业微信组织通讯、交易结算（Stripe / 微信小店）、云盘数字资产（文件/目录）、业务主数据（项目与课程、订单与退款、分润规则与明细、工资条、平台用户、用户实名证件）实时/定时入库。
- **智能转写与总结预处理**：自动解析会议录制，提取结构化转写文本、平台用户发言片段与发言人总结，异步生成周期跟踪报告。
- **商业激励与财务对账闭环**：订单权益天数计算与主动冻结/调整；按月度固定或模块摊销核算分润；基于 Cron 调度引擎自动冲销追回已结算退款；生成月度工资条。
- **数字资产与业务绑定**：网盘文件与商品详情媒体、项目/课程封面直接建立引用归档，形成统一资产索引。
- **组织级数据隔离与多租户治理**：所有业务操作严格穿透并绑定组织上下文（`organizationId`）；支持用户实名凭据加密审核与 JWT 批量吊销。
- **Agent 数据调用**：外部 Agent 通过 MCP / Skill / API / CLI 按需消费组织数据，实现高效、合规的智能分析。

## 范围边界（v1.0）

- **包含**：
  - 核心生态接入（腾讯会议、飞书、企业微信、Stripe、微信小店、云盘存储等，详见 [数据源接入矩阵](./data-sources.md)）；
  - 组织级多租户所有权隔离（Org Scoping）与人机统一权限治理；
  - 业务数据闭环（项目与课程、订单与退款、分润追回、工资条、实名证件）；
  - 轻量 AI 预处理与异步任务引擎（BullMQ）；
  - 多协议开放接口（RESTful API / GraphQL / MCP Server / Skill / nove-cli v1.3.0）；
  - nove-admin 现代化管理工作台（16 大业务与管理模块）。
- **暂不包含**：
  - 个人消费级市场（个人 AI 数据/记忆产品，另行立项）；
  - 原生移动端 App / 桌面客户端；
  - 独立自研的重量级 `nove-ai` 服务（当前阶段由外部成熟 Agent 代办重型关联任务，见 [能力状态总览](./capabilities.md)）；
  - 跨公网数据联邦与公有云商业化多租户自助计费平台。
