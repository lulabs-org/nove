# 目标与成功指标

> 本文档承接 [项目概述](./overview)，明确 nove 数据仓库的项目目标、建设原则与可量化的成功指标（KPI）。

## 项目目标

- 严格的人机权限：AI 以独立身份接入，最小授权、全量审计，AI 只能在授权范围内访问数据（第一优先）。
- 多协议开放：通过 API、MCP、Skill、CLI 等接口对外提供数据交互，服务 AI、Agent 与第三方系统。
- 建设组织级数据基础设施：多源数据实时/定时汇聚、统一存储、权限隔离，让组织数据成为 AI 可安全调用的资产。
- AI 实时预处理：自动总结、字段映射、实体抽取；自动发现数据间的关联与联系，形成有机结合的数据资产。
- 可拓展数据格式：内置数据仓库格式，支持以自定义方式（插件或其他形式）接入新数据形态。
- 交付最小可用应用（nove-admin，Web），作为人类查看与操作入口。

## 建设原则

- 以人为本：AI 增强而非替代，人类保留最终判断权。
- 价值优先：围绕真实使用场景交付最小可用版本（MVP）。
- 渐进迭代：小步快跑、连续集成，数据与能力持续进化。
- 可替换性：模块化边界清晰，技术栈可演进、实现可替换。
- 权限为本：数据访问（尤其是 AI 访问）始终受控、可审计。
- 扁平协作：信息直达、减少流程摩擦，强调交付与反馈闭环。

## 成功指标（KPI）

> KPI 随 v2.1 定位（组织级 Agent 数据基础设施）调整：**安全合规指标为第一优先，Agent 采纳为业务核心**。

### 安全与合规指标（第一优先）

- **权限违规** = 0，敏感信息泄露 = 0，审计记录完整率 = 100%

### 核心业务指标（Agent 采纳与数据开放）

- **Agent 调用**：≥ 3 个外部 Agent 通过 API / MCP / Skill 稳定调用
- **数据汇聚覆盖**：核心数据源 100% 接入，自动沉淀率 ≥ 90%
- **AI 预处理覆盖率**：入库数据自动预处理（总结 / 抽取）覆盖率 ≥ 80%
- **自定义接入**：新增一类数据源接入耗时 ≤ 1 周（插件化后 ≤ 2 小时）

### 技术性能指标

- **数据接入可靠性**：核心数据源（会议 / 订单 / 用户）接入成功率 ≥ 99%
- **系统响应性能**：API 平均首响 < 300ms，99% 分位数 < 1s
- **系统可用性** ≥ 99.5%，故障恢复时间 < 5min
- **接口吞吐**：峰值 QPS > 500

### 用户体验与运营效率指标

- **管理员满意度** ≥ 4.2/5（内测问卷）
- **数据时效**：实时数据源入库延迟 < 5min，定时数据源按计划完成
- **数据质量**：重复数据率 ≤ 5%，数据完整性 ≥ 95%
- **成本控制**：AI 模型调用成本/月 ≤ 预算目标，资源利用率 ≥ 75%
