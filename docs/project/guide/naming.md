# 项目名称：nove

## 名称含义

**nove** - 源自拉丁语"novus"，意为"新的、创新的"，体现了我们对数据基础设施与 AI 应用革新的理念。

## 命名理念

- **N** - **New**: 全新的数据基础设施范式，突破传统数据孤岛
- **O** - **Organized**: 有机结合的数据资产，AI 自动建立数据间的关联
- **V** - **Versatile**: 多协议接入（API / MCP / Skill / CLI），适应不同消费方
- **E** - **Empowered**: 以严格权限赋能 AI 与 Agent，让数据安全地服务于智能体

## 品牌定位

nove 的品牌定位是 **组织级 Agent 数据基础设施（数据网关）** —— 让组织数据成为 AI 与 Agent 可以安全调用的资产。定位详解见 [项目概述 · 系统定位](/project/guide/overview)。
