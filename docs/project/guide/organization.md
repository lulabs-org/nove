# 组织与运营

> 本文档承接 [项目概述](./overview.md)，汇总 nove 项目的组织与分工、风险应对、预算与资源。

## 组织与分工

- 项目负责人（Owner）：杨仕明（目标范围、里程碑、对外沟通）
- 技术负责人/后端：叶俊（架构 / 数据接入 / 权限体系）
- 后端/集成：明轩（数据接入与接口实现、分支协同）
- AI 服务：1 人（nove-ai：预处理、关联引擎、Job）
- 前端：1 人（nove-admin、鉴权与可观测）
- 产品/文档：1 人（需求澄清、原型、验收标准、手册）
- 运维/安全：0.5 人（权限、审计、告警、灰度与发布）

## 风险与应对

- 数据源接入复杂度高 → 契约优先、统一连接器、插件化、沙箱数据先通
- LLM 效果波动 → 离线评测集、结构化输出、可追溯引用、降级兜底
- AI 访问权限风险 → 人机统一权限、最小 scope、全量审计、数据脱敏
- 资源节奏与并行冲突 → 分支并行、场景优先级、双周可交付
- 技术选型演进 → 模块边界清晰、接口稳定、可替换实现
- 数据敏感与合规 → 最小权限、脱敏、审计闭环、分级授权

## 预算与资源（估算）

- 人力：3–5 人 × 3 个月
- 基础设施：数据库 / 向量库 / 日志监控 / 对象存储
- 第三方：飞书开放平台、腾讯会议、语音转写 / 模型调用
- 费用：按自研 / 云服务策略细化，随里程碑滚动评估
