# 组织与交易

## 组织域

`features/organization/` 包含三组管理界面：

- 本地用户：用户 CRUD、状态/资料维护和 Excel/CSV 导入入口。
- 平台用户：外部平台身份列表、详情和本地用户关联。
- 成员与角色：组织成员、部门结构、角色及角色权限绑定。

“本地用户”“平台用户”“组织成员”不是同一个实体的三个名称。开发跨模块选择器时应保留对应 ID 语义，不以显示名称或手机号替代稳定标识。

## 交易域

`features/transactions/` 包含：

- 产品：产品资料和启停状态。
- 渠道：订单来源渠道及其状态。
- 订单：订单列表、创建和状态维护，并关联用户、产品和渠道。
- 订单售后：退款记录创建、更新、结算、重开和删除。

订单表单中的用户、产品和渠道选项由各自组件封装，并有独立测试。历史订单需要继续显示已停用关联项；创建新记录时则应遵循接口提供的可选范围。

## 变更注意

- 创建/编辑 DTO 以生成类型和后端接口为准。
- 列表响应常带分页元数据，不要只缓存 `items` 后丢弃查询上下文。
- 删除、结算、重开和状态切换属于独立权限动作，页面读取权限不足以授权这些操作。
