# 模块地图

业务代码位于 `src/features/`，按管理职责分为以下区域：

| 区域       | Feature                        | 当前职责                             |
| ---------- | ------------------------------ | ------------------------------------ |
| 入口       | `auth`, `dashboard`, `errors`  | 登录、企业概览、404                  |
| 组织       | `organization`                 | 本地用户、平台用户、成员、部门和角色 |
| 交易       | `transactions`                 | 产品、渠道、订单和订单退款           |
| 内容与运营 | `meetings`, `reports`, `tasks` | 会议、追踪报告和后台任务             |
| 治理       | `governance`                   | API Key、权限资源和服务配置          |
| 设置       | `settings`, `account`          | 企业信息、个人资料和安全设置         |

模块目录的形状按复杂度演进，并不要求每个模块都有完全相同的层级。判断模块边界时，以业务生命周期、权限和 API 归属为主，而不是页面数量。

## 维护原则

- 页面细节留在源码和测试中，文档记录稳定的职责与跨模块规则。
- 新增或移除菜单模块时，同步更新本页与[路由与权限表](/reference/routes-and-permissions)。
- 后端才是数据约束和权限执行的最终边界；本页不复制后端 DTO 全量字段。
